# One triage gesture: delegate contract

Every delegate working on this change reads this file first and follows it exactly.
It is the single source of truth for the recipe, the verification contract, and the
fences. Do not edit this file.

Full design rationale: `docs/plans/keyboard-and-triage-state-model.html`.

## The target state

Comma had three ways to remove a conversation from view. It ends with one.

- **Settle** is the only triage gesture. It clears the `unresponded` and `waiting`
  flags, both at once when both are set. It is a toggle keyed to conversation
  state, not to the current lens: on a settled conversation the same control
  un-settles.
- **Later is deleted.** Zero production uses, ever.
- **Archive is deleted as a concept.** Nothing is hidden from the All lens any
  more, so the thing Archive did no longer exists.
- **SmartCloser is deleted.** Built but inert; no client code branches on it.
- A **Settled lens** replaces the Archived lens in the same slot.

A settled conversation returns when the other person sends a message, or when the
user un-settles it by hand. There are no deadlines and no restore qualifiers.

## Recipe, in order

Units are sequenced subtract-first and each ends in a check. Do not start a unit
until the previous one is green. Do not batch checks.

1. Delete SmartCloser.
2. Delete Later.
3. Delete Archive.
4. Add the Settled lens.
5. Rework the keyboard.
6. Undo stack.

## Verification contract

After every unit, from `apps/imsg`, all three must pass:

```bash
bun run lint          # warnings are pre-existing and acceptable; errors are not
bun test              # baseline is 655 pass / 0 fail across 82 files
cd .. && cd .. && bun run typecheck:imsg   # from the repo root
```

The typecheck command is the repo-root script `typecheck:imsg`, which runs
`bunx tsc -b` in `apps/imsg` then `bunx tsc --noEmit` in `client`. Use that exact
command. It is what the deploy gate runs.

A unit is not done when the code compiles. It is done when the suite is green and
you have read your own diff.

Tests that assert deleted behavior get deleted with it. Tests that assert
surviving behavior get updated, never weakened to pass. If a test fails for a
reason you did not intend, stop and report rather than adjusting the assertion.

## Facts already established

Do not re-derive these. They were measured or read at `f408980`.

- The client never sees a dismissal GUID. `ChatSummary` exposes only derived
  `flags` plus `laterUntil`. A settled conversation is therefore identified
  client-side as `lastMessage !== null && !flags.unresponded && !flags.waiting`,
  which is equivalent by construction once Later is gone.
- `computeFlags` already implements the decided restore rules. The only change it
  needs is removing the `laterActive` term. Do not otherwise alter the
  derivation.
- Three gates currently block the triage shortcut: a 768px width gate on the list
  keyboard adapter, the glide-mode scope gate, and a lens gate in
  `messages-workspace.tsx` that refuses unless the active filter matches the
  conversation's flag. The lens gate is removed outright.
- Only `dismiss` currently carries an optimistic-concurrency anchor. `later` and
  `archive` do not. The surviving gesture keeps the anchor and its 409 handling.
- `matchesFilters` has no `default` arm, so the compiler catches a missing lens
  case. Lean on that.

## Keyboard, final state

Global chords, fire while typing (`scope: "global"`, `allowInEditable: true`):

| Key | Command |
|---|---|
| `mod+e` | Settle / un-settle |
| `mod+u` | Mark unread |
| `mod+shift+z` | Undo |
| `mod+k` `mod+f` `mod+i` `mod+shift+f` `mod+/` `mod+w` `mod+n` | unchanged |

Outside a text field, no mode (`scope: "global"`, `allowInEditable: false`):
`j` `k` and the arrows navigate; `enter` focuses the composer.

Glide only (`scope: "list"`): `enter` activates the selected row. That is the sole
remaining list-scope binding.

Deleted as bare keys: `e` `u` `z` `h` `c` `/` `?`.

`mod+shift+z` rather than `mod+z` is deliberate. The dispatcher listens on the
capture phase, so a global `mod+z` would take the chord away from the composer's
own text undo entirely rather than sharing it.

`c` is safe to delete because `mod+n` reaches the app through the Tauri native
menu (`desktop/src-tauri/src/lib.rs`). The registry comment calling `mod+n`
browser-reserved is stale.

## Behavior rules

- When the gesture does not apply to the selected conversation, show a toast
  saying so. Never fail silently. Silent failure is the specific defect this
  change exists to fix.
- Forward triage writes send the last-message GUID the user saw and surface the
  server's 409 as "Conversation changed. Review the newest message."
- Undo bypasses the anchor check. Undo restores a flag rather than clearing one,
  so it cannot hide an unseen message.
- Undo is one shared stack across all surfaces, roughly ten deep, held in memory
  and discarded on reload.
- The Settled lens freezes membership, like Unread does, so a row does not vanish
  while it is being read.
